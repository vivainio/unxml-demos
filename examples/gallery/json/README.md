# Canonical JSON demo sources

- `openapi-petstore.json` — the Swagger Petstore OpenAPI document from
  <https://petstore3.swagger.io/api/v3/openapi.json>. Swagger Petstore is
  licensed under Apache-2.0.
- `json-schema-2020-12.json` — the official JSON Schema Draft 2020-12
  meta-schema from <https://json-schema.org/draft/2020-12/schema>. The JSON
  Schema specification is available under BSD-3-Clause or AFL-3.0.
- `geojson-feature-collection.json` — the FeatureCollection example from
  [RFC 7946 section 1.5](https://www.rfc-editor.org/rfc/rfc7946.html#section-1.5).
  Code components extracted from the RFC are provided under the Simplified
  BSD License described by the IETF Trust Legal Provisions.

The files are vendored so demo generation stays deterministic and offline.
